## 保存哪些信息

当你主动选择“使用 GitHub 登录”后，本站会保存 GitHub 提供的账户标识、用户名、头像和电子邮箱，以及你阅读过的文章标题、文章地址、阅读位置、学习计划选择、章节完成勾选、你填写的章节熟练度、复习时间、每日文章得分、获得的经验值、阅读次数和最近阅读时间。如果你主动收藏文章片段，本站还会保存所选文字、对应文章与章节、片段起止位置、包含公式或图片的片段排版副本、你填写的批注和收藏时间。电子邮箱只用于识别登录账户；本站不会读取你的仓库内容，也不会保存 GitHub 密码。

## 为什么保存

这些信息只用于在不同设备之间同步阅读历史、学习计划和你主动收藏的文章片段，显示最近阅读内容、计算章节完成度、生成基于复习时间的熟练度遗忘曲线，以及按每日最终学习状态计算不会因遗忘而倒扣的经验值和等级。曲线中的未来数值是依据页面公开展示的指数衰减公式计算的预测，并不代表考试成绩。未登录访客不会产生个人阅读历史或收藏记录。

## 谁可以看到

每个用户只能读取和修改自己的阅读记录与收藏片段。身份认证由 GitHub 和 Supabase 完成，相关记录保存在 Supabase 数据库中；相关服务也可能按照各自政策保存必要的安全与运行日志。

## 如何控制数据

你可以在“阅读记录”面板中暂停这台设备的同步、删除单篇记录、清除全部阅读记录或退出登录；收藏片段可以在 My Learning 中逐条删除。两类记录彼此独立，清除阅读记录不会自动删除收藏。记录会一直保留到你主动删除，或者本站停止提供这项功能。

如需删除账户关联信息或询问数据使用情况，可以通过 [GitHub](https://github.com/jiangpf2022) 联系站点所有者。
